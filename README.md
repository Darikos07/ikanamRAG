# ikanamRAG

Проект направлен на создание тематического корпуса текстов на основе материалов сообщества **Иканам** для дальнейшего использования в системах извлечения знаний, семантического поиска и RAG.  
Корпус позволяет сохранить, структурировать и анализировать содержание сообщества за весь период его существования: посты, статьи и комментарии к публикациям.

## Описание проекта

Основная идея проекта — собрать текстовые материалы сообщества, очистить их от технического шума, разделить на смысловые фрагменты и подготовить к дальнейшему использованию в RAG-системе.

Такой корпус может использоваться для:

- интеллектуального поиска по архиву публикаций;
- построения внутренней базы знаний;
- анализа динамики тем и обсуждений;
- создания тематических дашбордов;
- подготовки данных для RAG-ассистента.

## Задача проекта

В рамках проекта нужно было:

1. Собрать доступные текстовые данные из сообщества **Иканам**:
   - посты;
   - статьи из раздела публикаций;
   - комментарии к постам при наличии доступа.

2. Подготовить данные к анализу:
   - очистить текст от HTML-тегов, ссылок, лишних символов и технических артефактов;
   - обработать пропуски и дубликаты;
   - привести данные к единому табличному формату;
   - сохранить ссылки на исходные публикации.

3. Разделить длинные тексты на смысловые фрагменты — чанки:
   - использовать автоматическое деление текста;
   - сохранять идентификатор документа и чанка;
   - фиксировать источник текста и тип контента.

4. Подготовить данные для RAG:
   - сформировать эмбеддинги текстовых чанков;
   - построить FAISS-индекс для быстрого семантического поиска;
   - сохранить промежуточные и итоговые файлы.

5. Провести первичный анализ корпуса:
   - посмотреть динамику публикаций;
   - изучить активность по времени;
   - проанализировать распределение комментариев;
   - выделить основные закономерности в данных.

## Данные

В проекте используются текстовые данные из сообщества **Иканам** во ВКонтакте.

Собирались следующие типы материалов:

- текстовые посты сообщества;
- статьи и публикации;
- комментарии к постам;
- ссылки на исходные материалы;
- даты публикаций;
- идентификаторы документов.

При этом в корпус не включались персональные данные пользователей, информация об авторах, реакции, лайки и репосты, так как основной фокус проекта — именно текстовое содержание.

## Структура итогового датасета

После обработки тексты приводятся к структуре, удобной для дальнейшего использования в RAG-системе.

Пример логики хранения данных:

| Колонка | Описание |
|---|---|
| `document_id` | идентификатор исходного документа или публикации |
| `chunk_id` | номер текстового фрагмента внутри документа |
| `title` | название или краткое описание материала |
| `chunk_text` | очищенный текстовый фрагмент |
| `source` | ссылка на исходную публикацию |
| `comment` / `content_type` | тип контента: пост, статья или комментарий |

Такой формат позволяет не только хранить очищенный текст, но и понимать происхождение каждого чанка.

## Что реализовано в проекте

В репозитории реализован полный пайплайн подготовки корпуса:

### 1. Парсинг данных

В ноутбуке `parser.ipynb` выполняется сбор исходных данных:

- подключение к VK API;
- получение публикаций сообщества;
- сбор текстов постов;
- получение комментариев;
- сохранение исходных данных для дальнейшей обработки.

### 2. Предобработка данных

В ноутбуке `data_preprocess.ipynb` выполняется очистка и подготовка данных:

- удаление HTML-разметки;
- удаление ссылок и технических символов;
- обработка пропущенных значений;
- объединение постов и комментариев;
- приведение данных к единому формату;
- сохранение очищенного датасета.

### 3. Анализ и проверка гипотез

В ноутбуке `hypothesis.ipynb` проводится первичный анализ корпуса:

- анализ количества публикаций;
- исследование активности по дням и времени;
- анализ комментариев;
- поиск закономерностей в динамике публикаций.

### 4. Чанкинг и эмбеддинги

В ноутбуке `chunking_and_embeddings.ipynb` данные подготавливаются для семантического поиска:

- длинные тексты делятся на смысловые чанки;
- каждому чанку присваиваются идентификаторы;
- сохраняется информация об источнике текста;
- строятся эмбеддинги с помощью `SentenceTransformer`;
- создаётся FAISS-индекс для быстрого поиска похожих текстовых фрагментов.

## Как запустить проект

1. Склонировать репозиторий:

```bash
git clone <ссылка-на-репозиторий>
cd <название-репозитория>
```

2. Установить зависимости:

```bash
pip install -r requirements.txt
```

3. Для повторного сбора данных создать файл `.env` и добавить VK API token:

```text
token=your_vk_api_token
```

Файл `.env` нельзя загружать в публичный GitHub-репозиторий.

4. Запустить ноутбуки по порядку:

```text
parser.ipynb
→ data_preprocess.ipynb
→ hypothesis.ipynb
→ chunking_and_embeddings.ipynb
```

Если данные уже собраны, можно начинать работу с файла `ikanam_publications.csv`.

## Результат

В результате проекта был подготовлен корпус текстов сообщества **Иканам**, который включает очищенные публикации, комментарии и статьи. Данные были структурированы, разделены на чанки и преобразованы в эмбеддинги.

Итоговые артефакты проекта:

- очищенный датасет с публикациями;
- таблица текстовых чанков;
- эмбеддинги чанков;
- FAISS-индекс для семантического поиска;
- ноутбуки с парсингом, предобработкой, анализом и подготовкой данных.

## Возможное развитие проекта

Проект можно расширить до полноценного веб-приложения на Streamlit, которое будет визуализировать:

- количество и динамику постов по годам;
- тематическое облако ключевых слов;
- топ-темы и частотные фразы;
- фильтрацию контента по типу материала, году публикации и другим признакам;
- поиск релевантных фрагментов по пользовательскому запросу.

Также на основе подготовленного FAISS-индекса можно реализовать RAG-ассистента, который будет отвечать на вопросы по материалам сообщества.

## Вывод

Проект демонстрирует полный цикл работы с текстовыми данными: от сбора и очистки до анализа, чанкинга, построения эмбеддингов и подготовки индекса для семантического поиска. Полученный корпус может использоваться как основа для базы знаний, аналитического дашборда или RAG-системы.
