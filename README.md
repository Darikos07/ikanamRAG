# IKANAM RAG: семантический поиск по публикациям сообщества

Проект посвящён созданию пайплайна для сбора, очистки, анализа и подготовки текстовых данных сообщества **IKANAM** к семантическому поиску и RAG-системе.

В рамках проекта были собраны публикации и комментарии сообщества, проведена предобработка текстов, выполнен первичный анализ активности, а затем подготовлены чанки, эмбеддинги и FAISS-индекс для быстрого поиска релевантных фрагментов по смыслу.

## Цель проекта

Цель проекта — построить основу для интеллектуального поиска по материалам сообщества IKANAM.

Обычный поиск работает по точному совпадению слов, а семантический поиск позволяет находить материалы, близкие по смыслу к запросу пользователя. Такой подход может использоваться как база для RAG-системы: пользователь задаёт вопрос, система находит релевантные публикации и комментарии, после чего эти фрагменты могут быть переданы языковой модели для генерации ответа.

## Данные

В проекте используются текстовые данные из публикаций и комментариев сообщества IKANAM.

Основной датасет после обработки содержит **1044 публикации** и следующие поля:

| Поле | Описание |
|---|---|
| `post_date` | дата и время публикации |
| `post_id` | идентификатор поста |
| `post_source` | ссылка на исходный пост |
| `post_text` | текст публикации |
| `comment_text` | комментарии к публикации |

Для семантического поиска дополнительно подготовлен датасет с текстовыми чанками. Он содержит **2816 фрагментов** и используется для построения эмбеддингов и FAISS-индекса.

## Основные этапы проекта

### 1. Сбор данных

В ноутбуке `parser.ipynb` реализован сбор данных через VK API:

- выгрузка публикаций сообщества;
- получение текста постов;
- сохранение дат, id и ссылок на публикации;
- сбор комментариев;
- объединение постов и комментариев в единую таблицу.

### 2. Предобработка данных

В ноутбуке `data_preprocess.ipynb` выполнена подготовка текстов к дальнейшей работе:

- удаление HTML-тегов;
- очистка ссылок и технического мусора;
- обработка лишних символов и пустых значений;
- нормализация текстовых полей;
- группировка комментариев по публикациям;
- формирование итогового файла `ikanam_publications.csv`.

### 3. Анализ и проверка гипотез

В ноутбуке `hypothesis.ipynb` проведён первичный анализ активности сообщества:

- исследование публикационной активности по времени;
- анализ распределения постов по дням недели;
- изучение активности по часам;
- анализ количества комментариев;
- визуализация основных закономерностей.

Этот этап помогает лучше понять структуру данных и поведение аудитории сообщества.

### 4. Подготовка данных для семантического поиска

В ноутбуке `chunking_and_embeddings.ipynb` реализована подготовка базы знаний:

- объединение текстов публикаций и комментариев;
- разбиение длинных текстов на смысловые фрагменты;
- фильтрация слишком коротких и нерелевантных чанков;
- сохранение метаданных для каждого фрагмента;
- построение эмбеддингов с помощью `SentenceTransformer`;
- создание FAISS-индекса для быстрого поиска ближайших текстовых фрагментов.

## Как запустить проект

1. Склонировать репозиторий:

```bash
git clone <ссылка-на-репозиторий>
cd <название-репозитория>
```

2. Установить зависимости:

```bash
pip install -r requirements.txt
```

Или установить библиотеки вручную:

```bash
pip install pandas numpy requests beautifulsoup4 matplotlib sentence-transformers faiss-cpu langchain openpyxl python-dotenv
```

3. Для повторного сбора данных через VK API создать файл `.env` и добавить токен:

```text
token=your_vk_api_token
```

> Файл `.env` не должен загружаться в публичный репозиторий.

4. Запустить ноутбуки по порядку:

```text
parser.ipynb
→ data_preprocess.ipynb
→ hypothesis.ipynb
→ chunking_and_embeddings.ipynb
```

Если данные уже собраны и сохранены в репозитории, можно начинать работу с файла `ikanam_publications.csv` и запускать этапы анализа или подготовки эмбеддингов.
